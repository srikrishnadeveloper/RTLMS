# RTLMS — Realtime Log Management System

A realtime log management system: collect, stream, and inspect application logs from a web dashboard.

## Stack

- **React** (bootstrapped with Create React App)
- **JavaScript**

## Getting started

```bash
npm install
npm start     # dev server on http://localhost:3000
```

## Available scripts

| Command | Description |
|---------|-------------|
| `npm start` | Run the app in development mode with hot reload |
| `npm run build` | Production build into `build/` |
| `npm test` | Run the test runner in watch mode |

## Project structure

```
├── src/        # React application
├── public/     # static assets
└── package.json
```
